# ABCN — Afropean Business & Culture Network

A bespoke digital home for the Afropean Business & Culture Network.

## Stack
- Next.js
- React
- TypeScript
- Custom CSS motion system
- No generic icon library

## Public research used
The initial content direction is based on ABCN's public Instagram presence and public founder profiles/posts for Harmonie Essome.

Official Instagram: https://www.instagram.com/afropeanbusinessnetwork/

## Brand note
A reliable original ABCN logo asset could not be extracted from the public Instagram profile during research. The site therefore uses a custom interim ABCN mark rather than misrepresenting a fabricated asset as the official logo. Replace it with the original logo file when supplied.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
